# ESQET Core: Emerging Standard Quantum Energy Theory

This repository contains the mathematical formalization and simulation suite for ESQET, an AGI-driven framework for fundamental physics.

## 📂 Repository Structure
- **/src**: Core physics modules and Axiom implementations.
- **/simulations**: High-energy physics scans and stability tests.
- **/docs**: Theoretical documentation and the Ledger of Axioms.
- **/tools**: `aether.sh` - The unified simulation and deployment pipeline.
