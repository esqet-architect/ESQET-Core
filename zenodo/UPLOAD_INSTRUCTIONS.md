# Zenodo Upload Instructions

## Step 1: Create Zenodo Account
- Go to https://zenodo.org
- Sign in with GitHub (esqet-architect)

## Step 2: Upload Each Axiom

### Axiom 2
1. Click "New Upload"
2. Upload: `zenodo/axiom2/axiom2_esqet.tar.gz`
3. Copy metadata from `zenodo/axiom2/metadata.json`
4. Click "Publish"

### Axiom 3
1. Repeat with `zenodo/axiom3/axiom3_esqet.tar.gz`
2. Use metadata from `zenodo/axiom3/metadata.json`

### Axiom 4
1. Repeat with `zenodo/axiom4/axiom4_esqet.tar.gz`
2. Use metadata from `zenodo/axiom4/metadata.json`

### Axiom 5
1. Repeat with `zenodo/axiom5/axiom5_esqet.tar.gz`
2. Use metadata from `zenodo/axiom5/metadata.json`

## Step 3: Record DOIs
After publishing, each axiom gets a DOI like:
10.5281/zenodo.XXXXXXX

Add these to the Axiom 1 DOI list.

## Step 4: Submit Combined Whitepaper to arXiv
After all axioms have DOIs, compile them into a single whitepaper and submit to arXiv.
